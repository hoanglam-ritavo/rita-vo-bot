# Retired intent classifier

The learned intent classifier, off/observe/assist modes, artifact paths, offline
training, preparation/acceptance tools and Colab kit have been removed.
The source and prior evaluation history remain in Git; private `.tmp` data and
installed environments are untouched. Inherited retired env keys are ignored.

Use [catalog tasks and current evidence](catalog-answering.md) for deterministic
language recognition and [Type B](type-b-http.md) for bounded self-reference tasks.
There is no runtime classifier or source-hint observer.
